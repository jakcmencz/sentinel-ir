# Governance

sentinel-ir is maintained by one person, Jakub Rojicek
([@jakubrojicek11](https://gitlab.com/jakubrojicek11) on GitLab,
[@jakcmencz](https://github.com/jakcmencz) on GitHub), who reviews and merges
changes and cuts releases.

- **Where work happens:** the canonical repository is
  https://gitlab.com/jakubrojicek11/sentinel-ir. Issues and merge requests go there;
  the GitHub repository is a push mirror.
- **How changes land:** every change goes through a merge request with
  passing CI on Linux and Windows, Node.js 20, 22 and 24.
- **Releases:** only from GitLab CI on a protected tag, with npm provenance
  (see [SECURITY.md](SECURITY.md)).
- **Sponsorship:** sponsors buy visibility, never different findings. No
  sponsor can change what the analyzer reports, which packages it flags or
  how risk is scored.
- **Continuity:** if the maintainer can no longer maintain the project, the
  repository stays public under the Apache-2.0 license so anyone can fork it.
